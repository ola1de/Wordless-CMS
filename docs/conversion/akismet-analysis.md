# Akismet — conversion analysis (Milestone 4)

Static analysis of the Akismet plugin bundled with WordPress 7.1.5, run through the Wordless PHP parser (Milestone 4). Akismet is **NOT converted in M4**: it is a commercial spam-filtering service whose value is an external API and a spam database, not the PHP code around them. A translation of the PHP would still need the Akismet API (key, HTTP endpoints, account) and a spam-decision service — that is an integration (Phase 8), not a conversion. This report says, file by file, what a future conversion would face.
